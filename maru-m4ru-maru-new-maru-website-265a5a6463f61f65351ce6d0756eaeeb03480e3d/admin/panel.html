ADMIN GUIDE

操作説明

ページ

ページビルダーでブロックを並べ、下書き・公開・SEOまで管理できます。

メディア

画像URLと代替テキストをライブラリとして整理し、再利用できます。

履歴

保存時のスナップショットを残し、過去の状態へ復元できます。

デザイン

アクセント色、背景、角丸、最大幅などのデザイントークンを編集できます。

SEO

サイト全体のタイトル補助、説明、Robots、OGP画像を設定できます。

Undo / Redo

Ctrl+Z / Ctrl+Y、またはダッシュボードのボタンで編集を戻せます。

下書き

編集内容はブラウザのローカルにも自動保存され、次回アクセス時に復元を確認できます。

保存

保存すると既存のCloudflare Worker経由でGitHubへ反映されます。

ナビゲーション

通常リンクに加えて、公開CMSページをメニューへ追加できます。

ホームを編集

既存のホーム編集機能もそのまま利用できます。
